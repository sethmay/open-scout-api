How to read this map

  • Pin -- a surveyed coordinate (geo_precision: "exact"). Where the camp actually is.
  • Dashed circle -- an approximate coordinate (geo_precision: "approximate"). Backfilled from the camp's city or state centroid so the record has something, and frequently miles from the gate. Treat it as "somewhere around here", never as directions.
  • Listed below -- no coordinate at all. Dropping these would quietly shrink the dataset, so they are named instead of plotted.

One marker per property: camps that share a reservation are grouped, so a reservation with four camps is one pin listing four camps, not four pins on one spot.
